# 企业产品中的角色与利益相关者

## 概述

B端产品需要区分实际使用者、管理者、决策者、采购者和付费者等不同角色。

## 定义

企业产品中的利益相关者是参与产品购买、决策、使用、管理、维护或承担结果的不同组织角色。

## 核心内容

常见角色：
使用者 User
每天实际操作系统的人。
管理者 Manager
查看团队数据、配置规则、管理人员。
决策者 Decision Maker
决定是否采购或建设产品。
采购者 Buyer
负责采购流程、合同和供应商管理。
付费者 Payer
承担成本预算的角色。
IT / 安全 / 法务
负责系统集成、安全、合规或合同审核。
这些角色的目标可能不同。
例如：
销售人员希望：
少填表、多成交。
销售主管希望：
能够看到团队业绩。
老板希望：
提高整体销售效率。
IT希望：
系统安全、稳定、可集成。
因此B端需求分析不能只访谈一个人。

## 常见场景

- CRM
- ERP
- 企业AI
- 数据平台
- SaaS采购

## 产品经理关注点

- 产品经理需要建立角色—目标—痛点—权限—决策影响的完整关系。

## 常见误区

- 老板就是唯一用户
- 实际使用者就是客户
- 所有角色需求都应该同等满足
- 角色越多越好
