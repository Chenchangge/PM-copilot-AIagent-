# 工作流与流程引擎

## 概述

工作流系统将企业业务流程中的节点、条件、角色和动作配置化，使流程可以被执行和管理。

## 定义

工作流是按照预定义的流程节点和规则推动业务任务从开始状态向结束状态流转的机制。

## 核心内容

一个典型工作流包括：
流程
节点
节点类型
执行人
条件
输入
输出
状态
SLA
异常处理
节点可能包括：
人工审批
自动处理
条件判断
并行处理
子流程
通知
产品设计需要考虑：
流程定义 → 发布 → 执行 → 监控 → 异常 → 重新处理 → 归档

## 常见场景

- 审批系统
- CRM
- 财务
- 客服
- 企业AI Agent
- 自动化平台

## 产品经理关注点

- 流程引擎的价值在于把业务规则与流程执行能力系统化。

## 常见误区

- 工作流就是审批
- 流程越复杂越强大
- 工作流不需要异常处理
- 只要节点配置完成就能运行
