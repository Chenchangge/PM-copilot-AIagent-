# 用户增长的目的与基本框架

## 概述

用户增长的核心不是单纯增加用户数量，而是持续扩大能够获得产品价值并产生业务价值的用户规模。

## 定义

用户增长是围绕用户获取、激活、留存、转化、传播等环节，通过产品、运营、渠道和实验等手段改善用户生命周期表现的过程。

## 核心内容

常见增长框架：
Acquisition → Activation → Retention → Revenue → Referral
即：
获客
激活
留存
收入
推荐
实际产品中不一定严格按照线性顺序。
例如一个AI学习产品：
用户进入产品
→ 完成首次知识问答
→ 制定学习计划
→ 完成第一次学习
→ 完成模拟面试
→ 再次学习
→ 推荐给其他用户
增长分析需要关注：
用户规模
用户质量
用户生命周期
核心行为
留存
商业价值

## 常见场景

- 新产品增长
- 用户规模下降
- 新用户激活
- 留存优化
- 裂变活动
- 商业化增长

## 产品经理关注点

- 增长的目标应该与产品核心价值一致，不能只追求注册量。

## 常见误区

- 增长就是拉新
- 注册用户越多越好
- 补贴可以解决所有增长问题
- 增长团队只负责投广告
