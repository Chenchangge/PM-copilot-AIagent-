# 增长实验

## 概述

增长实验通过明确假设并进行小规模、可测量的验证，寻找能够改善用户生命周期指标的方法。

## 定义

增长实验是围绕增长问题提出假设，并通过实验验证具体增长方案效果的过程。

## 核心内容

基本流程：
问题
→ 数据定位
→ 提出假设
→ 设计方案
→ 明确指标
→ 实验
→ 分析
→ 复盘
例如：
问题：
新用户注册后大量流失。
假设：
“如果用户在注册后立即完成一个核心任务，激活率会提高。”
实验：
A：原流程
B：注册后直接进入核心任务
观察：
激活率
次日留存
核心行为
异常率

## 常见场景

- 激活
- 留存
- 获客
- 推荐
- 商业化

## 产品经理关注点

- 增长实验应该围绕明确问题，而不是为了“做实验”而做实验。

## 常见误区

- 实验越多越好
- 指标上涨就是增长成功
- 增长实验只做页面改动
- 实验结果可以脱离用户价值解释
