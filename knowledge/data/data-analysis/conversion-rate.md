# 转化率

## 概述

转化率描述用户从某个起点到完成目标行为的比例。

## 定义

转化率通常表示：
完成目标行为的用户数 / 进入该转化过程的用户数

## 核心内容

例如：
1000人进入注册页面
800人填写信息
700人提交成功
如果计算：
提交成功 / 进入注册页面 = 70%
但：
提交成功 / 填写信息 = 87.5%
两个指标都可能正确，但回答的问题不同。
因此分析转化率必须明确：
分母
分子
时间窗口
用户范围
去重方式

## 常见场景

- 注册
- 下单
- 付费
- 内容消费
- AI功能使用
- 营销活动

## 产品经理关注点

- 首先明确“转化从哪里开始、到哪里结束”。

## 常见误区

- 转化率就是成功人数/总用户
- 所有转化率都可以横向比较
- 转化率下降一定是页面问题
