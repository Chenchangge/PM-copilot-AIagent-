# 指标口径与维度

## 概述

同一个指标如果统计口径不同，得到的结果可能完全不同；维度则用于从不同角度拆分和比较指标。

## 定义

指标口径规定“这个指标到底怎么算”；维度规定“从什么角度观察这个指标”。

## 核心内容

例如：
指标：
支付转化率
可能定义为：
支付用户数 / 发起支付用户数
也可能定义为：
支付用户数 / 进入商品详情页用户数
两者不能直接比较。
常见维度：
时间
用户类型
渠道
地区
设备
产品版本
新老用户
用户等级
分析时常见结构：
指标 = Measure
维度 = Dimension
例如：
“本周整体支付转化率下降”
进一步拆：
新用户 vs 老用户
Android vs iOS
不同渠道
不同地区
不同版本

## 常见场景

- 指标异常
- 渠道分析
- 用户分群
- A/B测试
- 产品经营

## 产品经理关注点

- 遇到数据问题首先确认指标定义，而不是直接解释数字。

## 常见误区

- 同名指标可以直接比较
- 维度越多越好
- 指标下降一定意味着产品变差
- 指标口径只需要数据团队知道
