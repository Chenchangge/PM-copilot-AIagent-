# 漏斗分析

## 概述

漏斗分析通过观察用户完成一系列连续步骤时的流失情况，定位转化过程中的主要损失环节。

## 定义

漏斗由一组具有顺序关系的关键步骤组成，通过比较各步骤进入人数和完成人数来分析转化损失。

## 核心内容

例如电商：
访问商品页
→ 加入购物车
→ 提交订单
→ 支付
假设：
10000 → 5000 → 3000 → 2400
可以进一步计算：
页面到加购转化率
加购到下单转化率
下单到支付转化率
整体转化率
如果最后一步下降明显，需要继续分析：
支付方式
网络
价格
库存
页面问题
用户意愿
漏斗只能告诉你：
哪里损失明显
不能单独证明：
为什么损失

## 常见场景

- 电商
- 注册
- 付费
- 内容消费
- SaaS开通
- AI功能使用

## 产品经理关注点

- 漏斗用于定位问题环节，原因需要结合其他数据和用户研究继续验证。

## 常见误区

- 漏斗能直接告诉原因
- 所有步骤都必须严格线性
- 最大流失步骤一定最值得优化
- 漏斗数字下降就是产品问题
