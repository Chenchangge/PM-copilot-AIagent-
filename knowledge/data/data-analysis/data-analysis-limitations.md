# 数据分析的局限与因果关系

## 概述

观察到两个变量同时变化，并不能自动证明其中一个导致另一个变化；数据分析存在选择偏差、遗漏变量、口径变化等问题。

## 定义

数据分析中的相关性表示变量之间存在统计关联；因果关系则需要更强的证据和合理的因果识别方法。

## 核心内容

例如：
发现：
“使用AI学习功能的人留存率更高。”
不能直接得出：
“AI学习功能提高了留存。”
因为可能存在：
自我选择
用户本身更活跃
学习目标不同
渠道不同
用户阶段不同
进一步验证可以考虑：
A/B实验
自然实验
分层分析
回归等统计方法
用户研究

## 产品经理关注点

- 数据分析结论需要说明证据边界。

## 常见误区

- 相关性就是因果关系
- 大量数据就一定没有偏差
- 用户行为数据天然客观
- 统计显著就代表因果关系成立
