# 用户研究的目的与价值

## 概述

用户研究的核心不是“问用户喜欢什么”，而是通过系统方法理解用户、场景、行为、问题和动机，为产品决策提供证据。

## 定义

用户研究（User Research）是通过定性、定量或混合方法，系统收集和分析用户信息，以帮助团队理解用户需求、行为、问题和使用环境，并支持产品设计和决策的过程。

## 核心内容

用户研究主要解决几类问题：
### 1. 理解用户是谁
包括：
用户角色
用户任务
使用环境
使用频率
用户目标
### 2. 理解用户做什么
例如：
用户实际如何完成任务？
使用了哪些工具？
哪些步骤耗时？
哪些步骤容易出错？
### 3. 理解用户为什么这样做
行为背后的原因可能包括：
动机
习惯
认知
约束
环境
经验
### 4. 验证产品假设
例如团队认为：
“用户不使用这个功能，是因为入口不明显。”
研究可能发现真正原因是：
用户根本不知道这个功能能解决什么问题。
这两种原因对应完全不同的产品方案。

## 常见场景

- 新产品 0 到 1
- 新功能设计
- 用户流失分析
- 用户投诉分析
- 产品改版
- 用户需求探索

## 产品经理关注点

- 用户研究最重要的价值不是生成大量访谈记录，而是：
- 降低产品团队对用户的错误假设。

## 常见误区

- 用户研究就是用户访谈。
- 用户说什么就应该做什么。
- 研究样本越多越好。
- 用户研究只能用于产品早期。
- 做完研究一定能够得到唯一答案。
