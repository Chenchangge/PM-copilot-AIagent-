# 可用性测试

## 概述

可用性测试通过让真实或目标用户执行具体任务，观察其是否能够完成任务以及在哪里遇到困难，用于发现产品体验和交互问题。

## 定义

可用性测试（Usability Testing）是让用户完成具有代表性的任务，并观察其行为、困难和结果，以评估产品可用性的研究方法。

## 核心内容

一个基本流程：
确定任务 → 招募用户 → 设计测试 → 用户执行 → 观察记录 → 分析问题 → 优化方案
例如测试电商购买流程：
任务：
“请购买一件你认为适合夏天使用的产品，并完成下单。”
观察：
用户是否找到搜索入口；
是否理解筛选条件；
是否找到商品详情；
是否理解优惠；
是否能够完成支付。

## 常见场景

- 原型测试
- 新功能测试
- 页面改版
- 新用户 onboarding
- AI 产品交互测试

## 产品经理关注点

- 可用性测试重点关注：
- 用户能不能完成任务，以及为什么不能。
- 不是单纯询问：
- “你喜欢这个页面吗？”

## 常见误区

- 可用性测试就是让用户评价 UI 漂不漂亮。
- 测试必须等产品开发完成。
- 研究人员应该帮助用户完成任务。
- 用户完成任务就说明产品没有问题。
