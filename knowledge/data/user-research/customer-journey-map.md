# 用户旅程地图

## 概述

用户旅程地图通过描述用户完成目标过程中的阶段、行为、触点、情绪和痛点，帮助团队从完整体验而非单一页面理解问题。

## 定义

Customer Journey Map 是对用户从目标产生到任务完成过程中经历的主要阶段和触点进行可视化描述的方法。

## 核心内容

常见维度：
阶段
用户目标
用户行为
接触点
用户想法
用户情绪
痛点
机会点
例如在线购买：
产生需求 → 搜索 → 比较 → 查看商品 → 下单 → 支付 → 收货 → 售后
如果只优化“商品详情页”，可能忽略：
搜索阶段找不到商品；
支付阶段流程复杂；
收货后售后困难。

## 常见场景

- 电商
- 在线教育
- SaaS
- 旅游
- 金融
- 医疗服务

## 产品经理关注点

- 旅程地图最大的价值：
- 找到跨页面、跨渠道、跨部门的问题。

## 常见误区

- 用户旅程地图就是用户流程图。
- 只画产品内部页面即可。
- 每个用户只有一条旅程。
- 情绪曲线必须完全量化。
