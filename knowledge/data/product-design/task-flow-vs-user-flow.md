# Task Flow 与 User Flow

## 概述

Task Flow 更强调完成一个明确任务的线性步骤；User Flow 更强调真实用户在产品中可能经历的路径，包括分支、入口和决策。

## 定义

Task Flow 通常描述一个相对明确、单一目标任务的操作过程；User Flow 则可以包含多个入口、分支、条件和不同用户路径。

## 核心内容

例如：
Task Flow：
进入商品页面
→ 加入购物车
→ 提交订单
→ 支付
→ 完成
User Flow：
首页 → 搜索 → 商品页 → 加购 → 购物车 → 下单
但用户也可能：
首页 → 活动页 → 商品页 → 立即购买
或者：
订单页 → 再次购买 → 商品页
因此 User Flow 更适合描述真实产品中的多路径体验。

## 常见场景

- 电商产品
- SaaS产品
- AI产品
- 内容产品
- 复杂业务系统

## 产品经理关注点

- 根据问题复杂程度选择合适的流程表达方式，不要为了画图而画图。

## 常见误区

- Task Flow 和 User Flow 完全相同
- User Flow 一定比 Task Flow 更复杂
- 所有需求都必须画完整 User Flow
