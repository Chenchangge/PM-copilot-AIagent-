# 用户流程

## 概述

用户流程描述用户从进入产品或功能到完成目标过程中所经历的关键步骤、决策和状态。

## 定义

User Flow 是以用户目标为中心，对用户完成任务所经过的页面、操作、决策和结果进行结构化描述。

## 核心内容

设计用户流程时可以按照：
入口 → 触发 → 操作 → 决策 → 反馈 → 下一步 → 目标完成
例如一个在线学习流程：
首页
→ 选择学习方向
→ 选择知识点
→ 阅读知识
→ 标记开始学习
→ 完成学习
→ 系统记录学习进度
→ 推荐下一知识点
设计用户流程时需要重点检查：
是否存在不必要步骤
是否存在死路
用户是否知道下一步做什么
操作结果是否明确
返回后状态是否保留
异常后能否恢复

## 常见场景

- 注册流程
- 下单流程
- 内容学习流程
- AI对话流程
- 面试流程
- 审批流程

## 产品经理关注点

- 优秀的用户流程应该降低完成任务所需的认知和操作成本。

## 常见误区

- 用户流程就是页面跳转图
- 流程越短越好
- 只设计主流程
- 不需要考虑中途退出和返回
