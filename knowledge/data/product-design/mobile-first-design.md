# Mobile First 产品设计

## 概述

Mobile First 是优先围绕移动端有限屏幕、触控和使用场景设计核心体验，再逐步扩展到更大屏幕，而不是简单把PC页面缩小。

## 定义

Mobile First 是一种产品和界面设计策略，要求优先处理移动端的核心任务、信息优先级和交互限制。

## 核心内容

移动端设计需要考虑：
屏幕空间有限
单手操作
触控目标大小
键盘遮挡
网络不稳定
用户使用时间碎片化
横竖屏
返回行为
页面加载速度
设计原则：
优先核心任务
减少无关信息
控制操作层级
保持明显反馈
避免过小点击区域
避免复杂长表单
处理键盘和输入场景
保证移动端异常状态可用
Mobile First 并不意味着桌面端体验不重要，而是先解决限制更多的移动场景。

## 常见场景

- 学习产品
- 内容产品
- 社交产品
- 电商
- AI助手
- PWA

## 产品经理关注点

- 重点考虑用户实际使用场景，而不是单纯追求响应式适配。

## 常见误区

- Mobile First 等于只做手机
- 手机页面越简洁越好
- 响应式布局等于 Mobile First
- PC端功能可以全部原样搬到手机
