# 页面结构与信息层级

## 概述

页面结构决定用户看到什么、先看到什么以及下一步做什么；信息层级决定内容的重要程度和视觉、交互优先级。

## 定义

页面设计需要将功能、内容和操作按照用户任务进行组织，而不是简单罗列所有元素。

## 核心内容

一个典型页面可以考虑：
页面目标
核心信息
核心操作
辅助信息
次级操作
状态信息
帮助信息
设计时应考虑：
用户进入页面后，最重要的问题是什么？
例如知识详情页：
标题
→ 核心定义
→ 核心内容
→ 示例
→ PM关注点
→ 常见误区
→ 相关知识
→ 开始学习/完成学习
核心操作应该明显，但不应该让页面充满互相竞争的 CTA。

## 常见场景

- 首页
- 详情页
- 工作台
- 内容页面
- 移动端页面

## 产品经理关注点

- 优先保证任务完成和信息理解，再考虑视觉装饰。

## 常见误区

- 信息越多越完整
- 所有内容都应该同等突出
- 页面越短越好
- 页面设计只由 UI 设计师负责
