# 项目风险管理

## 概述

风险管理是提前识别可能影响项目目标的不确定因素，并采取监控、规避、缓解或应对措施。

## 定义

项目风险是尚未发生但可能影响项目范围、时间、成本、质量或结果的不确定事件。

## 核心内容

可以使用：
风险概率
×
风险影响
形成基础风险优先级。
风险类型包括：
技术风险
需求风险
资源风险
时间风险
外部依赖风险
数据风险
安全风险
合规风险
AI质量风险
例如AI项目：
风险：
模型输出质量不稳定
影响：
评价报告不可用
预防：
建立Golden Set
缓解：
结构化Rubric + Output Validation
兜底：
Fallback / 人工复核

## 常见场景

- AI项目
- B端项目
- 第三方接入
- 大版本开发

## 产品经理关注点

- 好的风险管理不是：
- 预测所有问题。
- 而是：
- 对高影响风险提前准备应对路径。

## 常见误区

- 风险就是已经发生的问题
- 风险越多越好
- 所有风险都必须消除
- 风险登记表只是形式
