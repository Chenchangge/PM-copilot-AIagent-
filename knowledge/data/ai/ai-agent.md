# AI Agent

## 定义

AI Agent（智能体）是能够「自主规划并执行多步任务」的 AI 系统：它不只回答一个问题，而是会拆解目标、调用工具、根据结果调整行动，直到完成一个复杂目标。可以理解为「会自己动手的 AI」。

## 核心内容

产品经理理解 Agent，要抓住「它和普通对话 AI 的区别」：

1. **普通对话 AI**：一问一答，用户主导每一步
2. **Agent**：给定目标后，自主拆解步骤、调用工具（搜索、计算、操作软件）、判断中间结果、迭代直到完成
3. **关键能力**：规划（拆任务）、工具调用（动手）、记忆（记住上下文）、反思（根据结果调整）
4. **典型例子**：能自己「查资料 → 整理 → 生成报告」的助手，而不是用户一步步问

Agent 的价值是「从帮用户想，到替用户做」，但风险也更高（自主行动可能出错）。

## 常见场景

- 面试被问「你如何理解 AI Agent，它和普通 AI 助手有什么不同」
- 设计「自动完成多步任务」的 AI 产品
- 评估「某个场景适不适合做成 Agent」

## 产品经理关注点

- 重点是「自主性带来的价值与风险」：Agent 能省事，但出错也更难控制
- 设计上要「给用户掌控感」：让用户能看清 Agent 在做什么、能随时干预
- 高风险动作要「人来确认」，不能全自动（如花钱、发消息）
- 不是所有场景都需要 Agent，简单的一问一答没必要「重」成 Agent

## 面试问题

### 1. AI Agent 和普通 AI 助手（问答机器人）有什么区别？

### 2. 设计一个 AI Agent 产品，你会如何处理「它可能做错事」的风险？

## 参考答案

### 问题 1

普通 AI 助手是「一问一答」，用户主导、模型只回答；Agent 是「给个目标，它自己拆解、调用工具、多步执行直到完成」。比如整理一份报告，问答助手需要你一步步问，Agent 能自己查资料、汇总、输出结果。核心区别是「自主规划和执行」的能力。

### 问题 2

我会分三块：一是「透明化」，让用户能实时看到 Agent 的每一步计划、执行和结果，而不是黑箱操作；二是「分级授权」，低风险动作自动做，高风险动作（花钱、发消息、删除）必须用户确认；三是「可回退」，保留操作记录、允许撤销。核心是「让 Agent 能干，但用户始终有掌控感和后悔药」。
