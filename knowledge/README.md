# knowledge — RAG 知识库

承载产品经理求职相关知识，供检索增强生成（RAG）使用。**当前阶段仅保留目录结构，尚未接入向量库。**

## 目录

- `data/` — 原始知识文档（Markdown / 文本等），作为知识来源
- `index/` — 向量索引（后续由 Chroma / FAISS 生成）
- `scripts/` — 文档处理与索引构建脚本（切分、embedding、入库）

## 技术选型（待定）

- Chroma 或 FAISS（二选一）
- Embedding 模型：待定

## 计划

1. 收集 PM 面试知识点（需求分析、数据分析、项目管理、面试技巧等）
2. 文档切分与向量化
3. 构建索引并提供检索接口
4. 供 AI 问答 / 推荐学习调用
