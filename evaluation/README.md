# evaluation — AI 面试评价

承载模拟面试的 AI 评价逻辑。**当前阶段仅保留目录结构，未实现具体评价。**

## 目录

- `prompts/` — 评价提示词（不同面试类型的评分标准）
- `schemas/` — 评分结构定义（维度、分数、建议等 JSON schema）

## 设计方向

- 多维度评分（如：产品思维、逻辑表达、数据意识、沟通协作）
- 输出结构化结果（总分、各维度得分、亮点、薄弱点、改进建议）
- 由后端 `services` 加载，前端仅展示结果

## 闭环作用

评价产出的「薄弱点」用于驱动推荐学习，形成学习 → 面试 → 评价 → 学习的闭环。
